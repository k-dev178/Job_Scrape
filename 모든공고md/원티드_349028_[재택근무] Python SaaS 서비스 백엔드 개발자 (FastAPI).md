## 회사 소개

"출시 2년 만에 전국 학교 보건실 30% 점유. 이제 우리는 학교를 넘어 일상의 건강을 기술로 연결합니다."
브레인다이브는 '스마일보건'을 통해 보건 행정의 디지털 전환을 이끌며 독보적인 성장세를 증명하고 있는 팀입니다. 우리는 단순히 기능을 만드는 것을 넘어, 현장의 문제를 가장 빠르고 우아하게 해결하는 데 집중합니다.
현재 네이버 클라우드(NCP) 환경에서 안정적으로 서비스를 운영 중이며, 새로운 시장으로의 확장을 앞둔 '퀀텀 점프'의 적기에 합류하실 핵심 백엔드 개발자를 찾고 있습니다.
불필요한 출퇴근과 대면 회의에 에너지를 쏟기보다, AI를 도구 삼아 코드의 본질에 집중하고 채팅으로 기민하게 소통하는 '스마트한 동료'를 기다립니다.

## 주요 업무

• 서비스의 심장 설계: FastAPI 기반의 고성능 백엔드 비즈니스 로직 설계 및 신규 API 고도화
• 매끄러운 인터페이스: Next.js 프론트엔드와 유기적으로 연결되는 효율적인 API 및 인터페이스 설계
• 견고한 인프라 운영: NCP(Naver Cloud Platform) 환경에서 24/7 중단 없는 서비스 유지보수 및 인프라 최적화
• 데이터 아키텍처: MySQL 등 RDB 아키텍처 설계 및 대용량 데이터 처리 성능 개선
• AI 기반 워크플로우: LLM(ChatGPT, Claude Code 등)을 적극 도입하여 코드 퀄리티를 높이고 운영 자동화 구현

## 자격 요건

• Python/FastAPI 스페셜리스트: FastAPI 프레임워크를 활용해 실무 API를 구축하고 배포해 본 경험
• Cloud Native: NCP 또는 AWS 등 클라우드 환경에서 서비스를 직접 운영해 보신 분
• Database Master: RDB(MySQL 등)의 스키마 설계부터 쿼리 최적화까지 능숙하게 다루시는 분
• Product Thinking: Next.js 기반 프론트엔드 구조를 이해하고, 개발 효율을 고려한 협업이 가능하신 분
• Remote Work Pro: 재택근무 환경에서도 텍스트 기반 소통을 통해 책임감 있게 성과를 만들어내시는 분
• AI Enthusiast: 최신 AI 도구를 업무의 일부로 활용하며 생산성을 극대화하는 분

## 우대 사항

• NCP 전문가: VPC, Cloud DB 등 네이버 클라우드 서비스 활용 능력이 높으신 분
• FE 이해도: Next.js의 Data Fetching 구조(SSR, ISR 등)에 대한 이해가 깊으신 분
• Security First: 보안 취약점을 고려한 시큐어 코딩 및 인증/인가 체계 구축 경험
• Growth Mindset: 스타트업의 빠른 속도감을 즐기며, 능동적으로 문제를 찾아 해결하는 성향
• Automation: Python 스크립트를 통해 반복적인 운영 업무를 자동화해 본 경험

## 혜택 및 복지

• "출퇴근 없는 일상": 1~2개월에 1회 오프라인 미팅을 제외하고, 전면 재택근무를 실시합니다. 거주 지역에 상관없이 최고의 퍼포먼스를 내주세요.
• "자율 기반의 신뢰": 마이크로 매니징이 없습니다. 결과물로 증명하는 문화를 지향하며, 필요한 업무 도구는 아낌없이 지원합니다.
• "성장의 기회": 시장 점유율 30% 서비스의 안정화와 신규 시장 확장을 동시에 경험하며 아키텍처의 성장을 주도할 수 있습니다.
