## 회사 소개

"매일 이용하는 배송 서비스, 그 뒤에 흐름을 최적화하는 회사"
[위밋모빌리티]
• 위밋모빌리티는 AI 기반 물류 지능화 솔루션을 만드는 기술 기업입니다.
• 자체 개발한 LIO(Logistics Intelligence Optimization)로 물류 데이터를 진단하고, 비용·시간·효율을 개선합니다.
• CJ대한통운, LX판토스 등 대형 물류기업과 관계에서 기술력을 인정받아 일본 라스트마일 플랫폼과 실증 사업까지 확장하여 글로벌 진출을 본격화하고 있어요.
• Series C투자 유치, 다수의 정부지원사업 수행, 수상 등 빠른 스케일업을 기록하고 있습니다.
[위밋모빌리티의 핵심 가치]
“효율적인 물류, 모두가 누릴 수 있도록”
규모나 업종에 관계없이 누구나 도입 가능한 물류 최적화 전략을 추구합니다.
우리는 고객이 겪는 물류의 비효율과 낭비를 LIO 서비스로 해결합니다.
[우리가 만들어가는 미래]
• 경로 최적화 기술 ‘ROOUTY’를 넘어 통합 물류 솔루션으로 진보하고 있습니다.
• 국내를 넘어 일본·동남아 등 글로벌 공급망 문제를 해결하는 물류 분야 기술을 선도합니다.
[지금이 합류할 최적의 타이밍!]
• 물류는 거대하고, 해결해야 할 문제는 더 큽니다.
• 당신의 의사결정 하나가 물류의 효율을 바꿀 수 있습니다.
위밋모빌리티에서 물류 솔루션의 새로운 기준을 만들어갈 분을 기다립니다.

## 주요 업무

• Apache Airflow 기반 통합 워크플로우 플랫폼을 단독으로 설계·구축·운영
• Airflow 코어 워크플로우 엔진과 인터페이스 게이트웨이 계층(Open API Service, Webhook Receiver, Outbound Connector)을 직접 구현
• Kubernetes 기반 배포·운영
• 데이터 엔지니어링 · 백엔드 API · DevOps 등 전 영역을 책임

## 자격 요건

• 백엔드·데이터·인프라 통합 개발 경력 8년 이상
• Apache Airflow 운영 및 DAG 개발 경험 필수
• PostgreSQL(Metadata DB), Redis 기반 분산 실행 환경 운영 경험

## 우대 사항

• 물류·SCM 등 대용량 배치 도메인 데이터 처리 경험
• API Gateway(Nginx Ingress, Kong) 및 OAuth2 / API Key 인증 연동 경험
• Object Storage(Pre-signed URL) 기반 대용량 결과 전달 설계 경험
• 메시지 큐(Dead Letter Queue) 및 이벤트 기반 아키텍처 설계 경험
• Scheduler 고가용성(HA) 및 무중단 배포 경험
• Kubernetes 운영 및 Helm Chart 배포 경험
