## 회사 소개

모시러는 고객이 필요한 시간만큼 전문 드라이버를 이용할 수 있는
시간제 수행기사 서비스입니다.
우리는 단순히 드라이버를 연결하는 서비스를 넘어,
고객의 이동 목적과 파트너의 운행 패턴을 데이터로 이해하고
더 좋은 매칭 경험을 만드는 플랫폼으로 성장하고 있습니다.
이번 채용에서는 모시러의 서비스 고도화를 함께 만들어갈 백엔드 개발자를 찾고 있습니다.
개발 환경
고객앱·파트너앱: JavaScript, React, React Native
API 서버: JavaScript(Node.js)
채팅 서버: TypeScript(NestJS) / DB: MS-SQL, MongoDB, Redis / 인프라: AWS, Azure
이런 분과 잘 맞습니다
• 단순 기능 개발보다 운영 문제를 시스템으로 해결하는 일에 관심 있는 분
• 백엔드 중심으로 일하되, 서비스 전체 흐름을 이해하고 싶은 분
• 고객, 파트너, 운영팀의 실제 사용 흐름을 고려해 개발할 수 있는 분
• 레거시 구조를 이해하고 점진적으로 개선할 수 있는 분
• 완성된 기획서만 기다리기보다, 질문하고 정리하며 함께 만들어가는 분
• 작은 개선이라도 빠르게 배포하고 검증하는 방식에 익숙한 분
합류 후 기대하는 역할
입사 초기에는 기존 API 서버와 관리시스템 구조를 파악하고,
운영팀에서 반복적으로 요청하는 기능 개선을 함께 처리합니다.
이후에는 예약, 배정, 파트너 관리, 매칭 추천, 리포트 자동화 등
모시러의 핵심 운영 시스템을 고도화하는 역할을 맡게 됩니다.
장기적으로는 단순 관리자 기능 개발을 넘어,
고객과 파트너 데이터를 기반으로 더 좋은 매칭 시스템을 함께 설계하게 됩니다.
