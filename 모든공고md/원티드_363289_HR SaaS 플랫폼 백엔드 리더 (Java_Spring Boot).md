## 회사 소개

AINJOB은 AI 기반 HR/채용 플랫폼을 신규 개발 중입니다. 이미 정의된 도메인 모델과 아키텍처 과제를 기반으로, 백엔드 구조 전반을 처음부터 함께 만들어갈 시니어 개발자를 찾습니다. 아키텍처 의사결정과 기술 표준을 직접 수립하는 역할입니다.

## 주요 업무

1. 도메인 모델링 및 ERD/DB 설계 (확장성·정합성·성능 중심)
2. Spring Boot 3.0 기반 모듈 구조 설계 및 기능 구현 리딩
3. AWS 인프라 설계 및 구축 (ECS/Fargate, RDS, SQS, Lambda, S3, VPC)
4. 개발 표준 정립 (코드 리뷰, API 규칙, 패키지 구조, 기술 문서화)
5. Dev/Stage/Prod 환경 구성 및 CI/CD 파이프라인 구축
6. 아키텍처 의사결정 주도 및 기술 방향 수립
7. 품질 리딩: 테스트 코드 기반의 품질 검증 및 기술 표준 정립
8. 핵심 API 개발
