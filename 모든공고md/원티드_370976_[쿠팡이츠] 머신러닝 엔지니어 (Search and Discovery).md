## 회사 소개

Coupang Eats Search & Discovery 팀의 Machine Learning Engineer는 고객이 원하는 음식, 매장, 아이템을 가장 빠르고 정확하게 발견할 수 있도록 검색 품질 전반을 책임집니다. 검색 퍼널의 전 레이어(retrieval, relevance, query understanding, intent expression, ranking 등)를 아우르며, 대규모 데이터와 최신 Machine Learning/Deep Learning 및 LLM 기술을 활용해 검색 시스템의 end-to-end 품질과 확장성을 지속적으로 고도화합니다. 또한 비즈니스 임팩트가 큰 문제를 정의하고 해결하며 여러 팀과 협업하며 Coupang Eats의 핵심 고객 경험을 혁신합니다.

## 주요 업무

• Coupang Eats Search 시스템의 end-to-end 설계, 개발, 운영 및 고도화 총괄
• 검색 시스템 전반(쿼리 이해, 의도 해석, retrieval, ranking 등)에 대한 아키텍처 설계 및 기술 방향성 수립
• 검색 퍼널 전반에 걸친 Machine Learning 및 foundational model 설계·개발
• 검색 품질 향상을 위한 LLM 기반 핵심 모델 설계 및 구축
• 대규모 데이터셋 분석을 통해 feature를 발굴하고 모델 성능 최적화
• 온라인 실험(A/B test 등) 전략 수립 및 분석을 통한 검색 품질 개선
• 한국 및 일본 시장, 복수 비즈니스 버티컬을 아우르는 검색 문제 해결 및 확장 전략 정의
• 검색 품질, 시스템 안정성, 확장성 간 trade-off를 고려한 기술 의사결정 주도
• 엔지니어링, 프로덕트, 비즈니스 조직과의 협업을 통해 핵심 고객 문제 해결
• Coupang Eats Search 영역의 Tech Leader로서 조직의 기술 방향성과 실행을 주도
