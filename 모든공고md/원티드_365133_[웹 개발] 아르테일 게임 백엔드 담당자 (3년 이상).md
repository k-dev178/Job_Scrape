## 회사 소개

러쉬에잇 주식회사는 아르테일을 비롯한 다양한 게임 서비스를 운영하며, 안정적인 라이브 서비스 운영과 신규 프로젝트 개발을 함께 진행하고 있습니다.
엔지니어링팀은 게임 서버, 운영툴, 데이터 플랫폼, 홈페이지, 인프라 등 서비스 운영에 필요한 다양한 시스템을 구축하고 운영합니다. 단순히 기능을 개발하는 것을 넘어 실제 서비스 환경에서 발생하는 문제를 해결하고, 운영 효율을 높이는 역할을 수행하고 있어요.
포지션 소개
이번 포지션은 라이브 서비스 백엔드 영역을 중심으로 운영툴, 로그 시스템, 데이터 연동, AWS 인프라 개선 업무를 담당하게 됩니다. 아르테일 서비스 운영 경험을 바탕으로 안정적인 운영 체계를 만들어가고, 향후 회사가 운영하는 클래식 메이플스토리 분야 전반으로 역할을 확장해 나갈 수 있는 포지션입니다.

## 주요 업무

• 아르테일 백엔드 서비스 유지보수 및 운영 요청 대응을 담당해요.
• 운영팀, CS팀, 기획팀이 사용하는 운영툴(Admin)과 권한 관리 시스템을 개발하고 운영해요.
• 로그 시스템과 데이터 플랫폼을 유지보수하고 필요한 데이터 추출 및 연동 업무를 수행해요.
• 운영 및 사업 부서의 요구사항을 기반으로 API 및 데이터 연동 기능을 개발해요.
• 현재 운영 중인 AWS 인프라를 분석하고 Terraform 기반 IaC 환경으로 개선하거나 재설계해요.
• 반복적으로 발생하는 운영 업무를 자동화하고 운영 효율을 높이는 기능을 개발해요.
• 서비스 장애 발생 시 원인을 분석하고 안정적인 운영 환경을 구축해요.
