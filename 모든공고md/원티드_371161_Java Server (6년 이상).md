## 회사 소개

[회사소개]
아하랩스는 “AI 기술로 모두의 일상을 이상적인 미래로 바꾼다”는 미션 아래 2018년 설립된 산업 AX 전문 기업입니다. 산업 빅데이터 통합관리 플랫폼 Data CAMP와 AIOps 플랫폼 DAISY를 통해 데이터 수집부터 AI 모델 개발, 배포, 운영, 재학습까지 전 과정을 하나로 연결하여, 산업 현장에서 실제로 작동하고 지속적으로 개선되는 AI를 구현합니다. 아하랩스의 솔루션은 전기차 배터리, 자동차, 전자·반도체, 항공우주, 방산 등 글로벌 산업 현장에 적용되어 운영 성과를 만들어내고 있습니다.

## 주요 업무

자사에서 개발한 'AI 관련 솔루션 및 웹 서비스' 의 코어 서버 개발 및 팀 리딩을 담당합니다. UI Application을 위한 고성능 API 제공과 서버 간 통신 & 관제 시스템 구축이 핵심 미션입니다.
1. 주요업무
• Java 서버 개발: Spring 프레임워크 기반의 솔루션 서버 및 API 개발
• DB 아키텍처 설계: MongoDB 를 활용한 대용량 솔루션 데이터 관리 및 최적화
• 시스템 고도화: 서비스 성능 최적화를 위한 백엔드 아키텍쳐 설계 및 지속적인 리팩토링
2. 보조업무
• 통신 및 관제: 대규모 서버 간 통신 프로토콜 설계 및 실시간 관제 시스템 개발
