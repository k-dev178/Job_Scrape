## 회사 소개

[주식회사 바이언스, 어떤 곳인가요?]
120년 전, 스페인의 신경생물학자 카할은 작은 광학 현미경으로 뉴런의 구조를 밝혀 노벨상을 받았습니다. 바이언스는 AI 기반 영상 분석 플랫폼으로 의생명과학자들에게 차세대 디지털 현미경을 제공합니다. 우리가 짠 코드 한 줄이 연구자의 분석 속도를 높이고, 그 결과가 수십만 명의 질병 치료와 생명 연장으로 이어질 수 있습니다.
2022년 창업 이후 씨드 투자 유치, 딥테크 TIPS 선정 등 기술력을 인정받으며 빠르게 성장 중입니다. 연구자를 위한 영상 분석 플랫폼과 WSI(Whole Slide Image) 기반 디지털 병리 영상 분석 솔루션을 핵심 제품으로 개발하고 있습니다.
바이언스는 연봉이 가장 높은 곳이 아닐 수 있습니다. 하지만 국내에서 가장 희소한 기술 스택을 프로덕션 환경에서 다루며, 내 코드가 인류의 과학적 발견에 직접 기여한다는 것을 매일 실감할 수 있는 곳입니다.

## 주요 업무

[합류하시면 이런 일을 합니다]
바이언스는 작은 팀입니다. 한 명 한 명의 기여가 제품 전체에 직접 연결됩니다. 설계부터 배포까지 오너십을 가지고 스스로 판단해야 하는 환경입니다. 아래 업무 중 "이거 해본 적 있다"는 항목이 많을수록 저희와 잘 맞습니다.
1) AI · 알고리즘 개발
기존 AI 모델을 실제 병리 데이터와 서비스 로직에 맞게 최적화·커스터마이징합니다. 장난감 프로젝트가 아닙니다. 실제 연구자들이 사용하는 서비스에 추론 파이프라인을 직접 붙이고, 성능과 안정성을 책임집니다.
기술 스택: Python, PyTorch
2) 대용량 데이터 시각화 (WSI · 고해상도 영상)
수 기가바이트급 병리 슬라이드 이미지를 효율적으로 처리·변환·전송하는 백엔드를 개발합니다. 국내에서 이 기술 스택을 프로덕션에서 다루는 곳은 손에 꼽습니다. 어떤 이력서에도 강력한 차별점이 될 경험입니다.
기술 스택: OpenSlide, CuSIM, Pyvips, OpenGL, GLSL
3) API 설계 · 구현
인증·권한·로깅·에러 처리를 포함한 프로덕션 수준의 API를 설계하고 구현합니다. AI 서빙, 시각화 파이프라인, 데이터 처리를 연결하는 핵심 레이어를 책임집니다.
기술 스택: Python, FastAPI
4) DB 설계 · 운영
대용량 데이터 저장·조회 요구사항에 맞춘 스키마 설계, 인덱스 최적화, 다중 DB 조합 운영을 담당합니다. Python ORM 기반의 데이터 접근 계층을 직접 구현합니다.
기술 스택: PostgreSQL, MongoDB, SQLModel
5) 서버 · 인프라 운영
Linux 기반 서버 운영부터 Docker 기반 배포 환경 구축, 분산·병렬 처리를 고려한 백엔드·인프라 아키텍처 설계까지 담당합니다. 환경 세팅에서 상용 배포까지 전체 사이클을 직접 경험할 수 있습니다.
기술 스택: Linux, Docker, Docker Compose, Python

## 자격 요건

아래 항목은 모두 해당되어야 지원을 권장합니다. 바이언스는 체계적인 온보딩과 단계적 업무 배분이 잘 갖춰진 환경이 아닙니다. 개발 경험이 적거나, 명확한 가이드 아래 일하는 것을 선호하신다면 더 좋은 성장 환경을 먼저 경험하신 후 지원해 주세요. 실력을 충분히 쌓고 오신다면, 그때 함께하고 싶습니다.

3) AI 모델 서빙을 위한 프로덕션 수준의 API를 구축한 경험
4) 기술 개발 방향을 스스로 기획하거나 리딩한 경험 (또는 이에 준하는 역할 수행 경험)
