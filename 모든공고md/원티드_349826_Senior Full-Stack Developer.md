## 주요 업무

왜 Avo에서 개발해야 하는가
AI 시대에 커리어가 정체될까 걱정된다면 — Avo는 그 반대 방향입니다.
만드는 제품이 AI입니다. LLM 기반 임상 의사결정, AI Scribe, 프롬프트 엔지니어링 — 당신이 짜는 코드가 AI 파이프라인 위에서 돌아갑니다. "AI 트렌드를 팔로우"하는 게 아니라, AI 제품의 코어를 직접 만듭니다.
만드는 방식도 AI입니다. Claude Code로 코드 리뷰하고, 페어 프로그래밍하고, AI 에이전트가 Slack에서 팀원처럼 일합니다. "AI 도입 검토 중"이 아니라 — 이미 일상입니다.
풀스택으로 전체 제품을 만듭니다. React 프론트엔드 + Python/Django 백엔드를 오가며, 노코드 빌더의 비주얼 프로그래밍 엔진부터 API 설계, 데이터 모델링, EHR 연동까지 — 한 기능의 처음부터 끝까지 책임집니다.
1. 풀스택 제품 개발
React/TypeScript 프론트엔드 + Python/Django 백엔드를 오가며, 노코드 빌더(AvoBuilder)와 임상 의사결정 지원 앱(CDSS)을 개발합니다. 의료진이 코드 없이 임상 워크플로우를 설계·배포할 수 있는 비주얼 프로그래밍 플랫폼의 핵심 로직을 구현합니다.
2. 플랫폼 아키텍처 설계
세 개 제품(Builder, Scribe, Ask Avo)이 공유하는 컴포넌트 추출·설계하고, B2B SaaS 플랫폼의 구조적 기반을 만듭니다.
단순 기능 구현이 아닌, 장기적으로 확장 가능한 시스템 구조를 설계하는 역할입니다.
3. 글로벌 팀 협업 & 고객 대응
미국 임상팀·디자인팀과 영어로 소통하며, US 병원 고객의 기술 이슈에 직접 대응합니다. 2주 단위 스프린트에서 요구사항에 대한 기술적 의견을 주도적으로 제시합니다. (한국 시간 기준 야간 대응이 있을 수 있습니다.)
4. AI-native 개발 프로세스
Claude Code, Cursor 등 AI 도구를 활용한 코드 작성·리뷰를 일상적으로 수행합니다. AI를 보조 도구가 아닌 핵심 워크플로우로 쓰는 팀에서, 개발 프로세스 자체를 혁신합니다.
