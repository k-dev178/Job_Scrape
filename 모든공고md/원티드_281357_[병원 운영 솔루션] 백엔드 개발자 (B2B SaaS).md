## 회사 소개

#더 좋은 미용의료 서비스를 누구나 누릴 수 있게
힐링페이퍼는 누구나 자신에게 맞는 병원과 의사를 만날 수 있도록 미용의료 시장을 혁신합니다.
우리는 시술 후기, 가격 등 정확하고 믿을 수 있는 정보로 미용의료 시장을 투명하게 바꿔나갑니다.
현재, 한국·일본·태국 등 전 세계 950만 명 이상의 사람들이 강남언니를 통해 자신에게 맞는 병원과 의사를 선택하고 있습니다.
힐링페이퍼는 단순한 정보 제공을 넘어, 미용의료 시장의 패러다임을 새롭게 제시합니다.
힐링페이퍼는 2023년 흑자 전환을 이루며, 더 큰 도약을 위한 준비를 마쳤습니다.
이제 우리는 한국을 넘어, 글로벌 No.1 미용의료 플랫폼을 향해 빠르게 나아갑니다.
미용의료 시장의 새로운 기준을 세우는 글로벌 서비스를 만들고 싶다면, 힐링페이퍼와 함께하세요.
＜함께할 ​팀을 ​소개해요＞
• KOS 팀은 ​미용 ​의료 ​병원 운영 체계를 ​새롭게 ​바꾸는 글로벌 SaaS를 ​개발하고 ​있어요.
• 개발자, ​PO, 디자이너가 하나의 ​제품에 몰입하며 ​병원과 ​환자 모두에게 ​혁신적인 경험을 ​제공해요.
• 단순한 ​고객 관리 툴이 ​아닌, 소프트웨어·의료 ​장비·병원 공간·인력 운영이 유기적으로 연계된 엔터프라이즈 시스템을 구축해요.
• AI를 적극적으로 활용하되, 기능을 빠르게 만드는 것보다 도메인 이해와 고객경험, 개발 철학과 코어 아키텍처에 대한 깊은 이해를 우선해요.
• 국내 미용 의료 분야 1위 플랫폼 강남언니와의 시너지를 활용해 글로벌 미용 의료 시장의 변화를 주도해요.
＜이런 경험과 성장을 할 수 있어요＞
• DDD와 EDA, TDD를 실제 프로젝트에 적용하며 전문성을 발전시킬 수 있어요.
• 복잡한 도메인과 비즈니스 문제를 이해하고, 효과적인 기술 솔루션으로 해결하는 능력을 키울 수 있어요.
• 코드를 한 줄씩 작성하는 시간은 줄어들지만, 읽어야 할 순간에 제대로 판단하는 엔지니어로 성장할 수 있어요.
• 글로벌 SaaS 제품을 개발하며 확장성, 성능, 보안을 고려한 엔터프라이즈급 시스템 구축 경험을 쌓을 수 있어요.
＜우리는 이런 도구를 사용해요＞
• 프로그래밍 언어: Java / Kotlin / TypeScript
• 프레임워크: Spring Boot / Spring Webflux / Express.js
• 데이터베이스: MongoDB
• 인프라: AWS / Kubernetes
• AI 개발 도구: Claude Code 등
＜우리는 이렇게 일하고 있어요＞
1. 도메인 주도 설계(Domain-Driven Design)
코드 구현의 비용이 빠르게 낮아지는 세상에서, 진짜 경쟁력은 도메인 이해의 깊이에 있어요. 유비쿼터스 언어와 전략적 설계에 집중해 도메인의 문제를 효율적으로 풀어내고 아키텍처 지속성을 확보하려 노력해요. 전술 기법에 매몰되면 작은 엔지니어링 재미는 느낄 수 있지만, 개발자 시야가 좁아지고 도메인 주도 설계의 진짜 가치를 취하지 못해요.
2. 이벤트 기반 아키텍처(Event-Driven Architecture)
Microservices 패턴이 유행하고 있지만, 모듈 관계에 HTTP 요청을 적용하는 것만으로는 문제를 해결하기보다 오히려 더 많은 문제를 유발할 수 있어요. 도메인 주도 설계에 기반해 시스템 내 경계를 설정하고, 분리된 요소들이 비동기 이벤트를 사용해 유연하게 통합되도록 아키텍처를 설계해요.
3. 테스트 자동화
테스트 자동화는 CI, CD, DevOps의 필요조건이에요. 코드가 더 빠르게 생산되는 환경일수록 테스트의 가치는 올라가요. 코드의 정확성을 검증하고 의도를 보장하는 테스트를 AI와 함께 설계해요. 우리는 자동화된 테스트 케이스를 늘리고, TDD를 적용하고, 시스템과 프로세스를 개선하고 있어요.

• 미용 의료 병원의 도메인과 비즈니스 문제를 깊이 이해하고, 이를 해결하는 제품 개발
• 오늘 만든 코드가 내일의 자원이 되는, 복리로 쌓이는 시스템 설계
