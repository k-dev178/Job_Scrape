# 백엔드 개발자(시니어) - 솔리샵

- 출처: 원티드
- 회사: 에이베러
- 경력: 5년 이상
- 원문: https://www.wanted.co.kr/wd/367541
- 공고번호: 367541
- 기술: TypeScript, Node.js, NestJS, MySQL, PostgreSQL, REST API
- 지역: 서울 강남구 강남대로 364, 12층 패스트파이브

## 회사 소개

에이베러는 브랜드와 소비자를 성과로 연결하는 구조를 설계하는 회사입니다.
우리는 단순히 광고를 운영하는 데 그치지 않고,
이커머스 시장의 비효율적인 비용을 줄이며 성과로 이어지는 연결 방식을 만듭니다.
예측보다 리뷰를, 완벽보다 완결을, 성과보다 문제 해결을 중시하며
매일의 결정과 실행에 공통된 기준과 방향성을 적용합니다.
에이베러는 이 구조를 통해 3년 안에 거래액 1조 원 달성이라는 목표를 향해 나아갑니다.
성과를 구조화 하는 에이베러 프로덕트
• 솔리샵 : 신뢰할 수 있는 리뷰 기반으로 브랜드의 실제 소비자를 연결해 진정성 있는 구매 경험을 공유합니다.
• 참새마트 : 일상의 모든 소비 행동(온라인 쇼핑, 콘텐츠 시청 등)을 가치로 변경해 광고의 목적과 소비자의 효용을 연결합니다.
• 디스터 : 쿠팡의 복잡한 데이터 속에서 AI를 활용해 핵심 인사이트 도출부터 의사결정까지 리소스를 최적화 합니다.

## 주요 업무

• 성장하는 솔리샵 플랫폼의 백엔드 아키텍처 설계·발전 주도
• 운영 중인 레거시 시스템의 점진적 개선·마이그레이션 설계 및 리딩
• 결제 / 포인트 / 정산 등 정합성이 중요한 도메인 설계·구현

• RDB(PostgreSQL/MySQL 등) 스키마 설계 및 쿼리 최적화 경험이 있으신 분
• Rest API 설계·운영 및 외부 시스템 연동 경험해 보신 분
• 운영 중인 서비스의 레거시 코드를 점진적으로 리팩터링·마이그레이션 직접해 보신 분
• 기술적 의사결정, 코드 리뷰, 동료 멘토링 등 팀 리딩 경험이 있으신 분
