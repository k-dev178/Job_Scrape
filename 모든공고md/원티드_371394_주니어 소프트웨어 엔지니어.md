## 회사 소개

AiderX는 독자적인 행동 예측 원천 기술을 바탕으로, 설치형(On-premise)과 클라우드를 아우르는 차세대 광고·추천 하이브리드 시스템을 만들고 있습니다.
광고와 추천은 수십억 건의 사용자 행동 데이터를 실시간으로 처리해야 하는, 가장 복잡한 기술적 도전 중 하나입니다. 우리는 이 문제를 흔한 오픈소스 조합이 아닌, 스스로 설계한 원천 기술로 풀고 있으며 — 궁극적으로 이 분야의 업계 표준 프레임워크가 되는 것을 목표로 합니다.
복잡하고 거대한 시스템의 문제를 해결해야 하는 만큼, 우리는 기술적 탁월함을 최우선 가치 중 하나로 삼습니다. 동료 간의 건강한 기술 토론과 솔직한 피드백이 일상인 환경에서, 몇 년 후 누구도 넘볼 수 없는 전문가로 성장할 분을 모십니다.

## 주요 업무

# 주요 업무
• 광고·추천·검색 기능을 하나의 플랫폼에서 통합합니다
• 온프렘과 클라우드 모두에서 유연하게 동작하도록 구현합니다
• 실시간 AI 의사결정으로 성과와 수익성 동시 최적화합니다
• 구축 기간과 비용을 혁신적으로 절감합니다
• 장기적으로 업계 표준이 될 기초 프레임워크 지향합니다
# 사용 기술
* Backend : Rust, Python, C++
* Frontend : Vue.js, React
* Infra : Kubernetes, Docker, Multi-Cloud(AWS, GCP, Azure)
# 이 팀에 합류하면 얻게 되는 것
* 수십억 건 규모의 실전 시스템을 직접 다룹니다.
- 단순한 API 개발을 넘어, 실시간으로 최적의 결과를 제공하는 추천·광고 엔진의 코어 아키텍처를 설계하고 운영합니다.
* 흔하지 않은 기술의 기여자가 됩니다.
- 흔한 오픈소스 조합이 아닌, 광고와 추천 기술의 근간이 되는 원천 기술과 이 분야의 표준이 될 기술에 기여자로 참여하게 됩니다.
* ‘Why’를 이해하는 엔지니어로 성장합니다.
- 단순히 기능을 만드는 것을 넘어 비즈니스에 미치는 영향과 고객의 문제 해결 과정을 함께 고민하며, 기술적 깊이와 제품을 성공시키는 감각을 동시에 갖춘 인재로 성장합니다.

## 자격 요건

# 태도와 문화
• 스스로 높은 기준을 세우고, 만족할 때까지 파고드는 집요함이 있는 분
• AI 도구를 능숙하게 쓰는 것을 넘어, AI가 내놓은 답을 그대로 받아들이지 않고 스스로 검증하며 더 나은 판단을 내리려는 분
• 빠르게 만드는 것에 그치지 않고, 왜 그렇게 만들어야 하는지를 끝까지 고민하는 분
• 동료로부터 배우려는 열린 마음과 겸손함을 가진 분, 그리고 자신이 배운 것을 다시 동료와 나누는 분
• 빠른 실행 속에서도 본질적인 학습과 성장을 놓치지 않는 분
• 아무리 뛰어나도 동료를 존중하지 않는 사람과는 함께하지 않습니다.
# 기술과 능력
• 복잡하고 큰 시스템을 두려워하지 않고 오히려 흥미로워하는 분
• 컴퓨터 과학(자료구조, 알고리즘, 운영체제, 네트워크 등)의 탄탄한 기초지식을 갖춘 분
• 하나 이상의 프로그래밍 언어를 깊이 있게 다루며, 그 경험을 직접 보여줄 수 있는 분 (GitHub 등)
• 복잡한 문제를 논리적으로 분해하고, 합리적인 해결책을 설계하는 분
• 자신의 아이디어를 명확한 글과 논리로 전달하고 동료를 설득할 수 있는 분
