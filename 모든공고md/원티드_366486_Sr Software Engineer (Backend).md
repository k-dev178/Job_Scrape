## 회사 소개

인포시즈는 제조·반도체·플랜트·금융 등 다양한 산업의 데이터를 AI가 실제 운영과 의사결정에 활용할 수 있는 구조로 연결하는 Enterprise AI Infrastructure 기업입니다. 플랜트와 제조 산업의 핵심 자산인 P&ID(Process & Instrumentation Diagram)에는 설비 구조와 공정 흐름, 운영 로직 등 복잡한 산업 정보가 담겨 있습니다.
Applied Scientist (Computer Vision)는 이러한 산업 도면을 AI가 이해 가능한 형태로 구조화하고, Vision 기술을 실제 운영 환경까지 연결하는 역할을 맡게 됩니다.
단순히 모델 Accuracy를 높이는 역할이 아닙니다. 복잡한 산업 데이터를 실제 문제 해결로 연결하는 역할에 가깝습니다.
이런 분을 찾고 있습니다
• 문제를 대충 넘기지 않고 끝까지 파고드는 분
• 단순 모델 성능보다 실제 산업 문제 해결에 더 관심이 있는 분
• 복잡한 데이터를 구조화하고 관계를 이해하는 문제를 좋아하는 분
• 논문 구현을 넘어 실제 운영 환경까지 연결하는 데 흥미가 있는 분
• 정답이 없는 문제를 스스로 정의하고 방향을 만들어갈 수 있는 분
• 어렵고 복잡한 문제를 해결하는 과정 자체를 즐기는 분
• AI가 산업의 운영 방식을 근본적으로 바꾸게 될 것이라 믿는 분
