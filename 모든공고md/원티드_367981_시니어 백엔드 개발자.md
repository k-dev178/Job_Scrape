## 회사 소개

비버웍스(BeaverWorks) 는 결제·정산 플랫폼 비버페이(BeaverPay) 를 운영하는 핀테크 회사이자, AI 네이티브 개발방식으로 회사 전체를 재설계하고 있는 회사입니다.
우리는 단순히 "AI 도구를 보조적으로 쓰는" 단계를 넘어, Claude Code, Codex 등 에이전틱 AI를 1차 개발 도구로 두고 비버페이의 차세대 버전을 새롭게 구축하고 있습니다. 결제 도메인 특성상 안정성·보안·코드 품질을 최우선으로 두면서도, AI를 통해 시니어 한 명이 과거 팀 단위로 해내던 일을 해내는 새로운 개발 방식 그 자체를 설계하는 단계에 있습니다.
이 전환을 함께 리드하고, 비버페이 백엔드의 장기적 진화를 책임져 줄 분을 시니어 백엔드 개발자분을 모십니다.

## 주요 업무

1. 백엔드 설계
• API 설계 : 비즈니스 요구사항을 RESTful API 명세로 직접 설계 (리소스 모델링, Request/Response, 에러코드 체계,인증/인가, 페이징, 버저닝 등)
• DB 설계 : 스키마·ERD·인덱스 전략·파티셔닝·마이그레이션 계획 직접 수립
• 아키텍처 설계 : 클린 아키텍처를 기반으로, 그 위에 헥사고날(Ports & Adapters)·DDD Bounded Context 를 결합해 도메인 모델, 레이어 구조, 모듈 경계, 의존성 방향, 외부 시스템 통합 방식을 정의. 의존성 규칙(domain application adapter) 을 코드·모듈·CI 레벨에서 강제하는 구조를 설계
• 기술 의사결정 : 라이브러리·프레임워크·인프라 컴포넌트 선택과 trade-off 판단
• AI를 위한 설계 문서화 : CLAUDE.md / AGENTS.md / Skill 등을 통해 AI가 일관된 출력을 내도록 컨텍스트와 가드레일 정립
2. AI 네이티브 개발 운영
• AI 에이전트를 활용한 구현 위임 및 검증
- 결제 도메인 핵심 비즈니스 로직(승인·취소·정기결제·정산·PG 연동)을 AI와 함께 구현하되, AI 출력을 SSOT로 두지 않고 도메인 관점에서 옳고 그름을 판단
• AI 생성 코드의 오류를 빠르게 잡아내는 코드 리뷰
• AI 개발 인프라 직접 설계 및 업그레이드
3. 비버페이 차세대 버전 개발 & 운영 & 유지보수
• AWS 기반 인프라 구축 및 CI/CD 파이프라인 설계·운영
• 결제 시스템에 요구되는 신뢰성·가용성·관측성 확보
• 현행 시스템의 안정적 운영, 장애 대응, 트러블슈팅
• 운영 이슈 핫픽스 및 점진적 개선
• 차세대 버전으로의 마이그레이션 전략 수립 및 단계적 전환
4. 커뮤니케이션
• Product / FE / Mobile / 운영팀, PG사 담당자와의 협업
• 비즈니스 요구사항을 도메인 모델·API 명세로 번역하는 커뮤니케이션
