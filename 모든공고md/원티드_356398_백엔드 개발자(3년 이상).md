## 회사 소개

덧셈 팀은 근로자, 알바, 프리랜서, 초기 영세 사업자들을 위한 세금 신고/환급 서비스를 만들고 있어요.
저희 팀은 세금 산업의 디지털 전환을 가속화하고, 하나의 견고한 산업으로 자리잡을 수 있도록 하는 미션을 갖고 있어요. 개인환급 서비스를 시작으로, 사업자 환급, 종합소득세 신고, 인건비 신고, 부가세 신고 서비스 등으로까지 확장하고 있어요.
2023년도 법인 설립 이후 누적 가입자 100만명, 누적 환급액 500억원을 돌파했어요.

## 주요 업무

• 서비스 코어 및 API 개발: Python, Django(DRF)를 기반으로 자사 서비스의 API 서버를 개발하고 운영해요.
• 운영 효율화를 위한 백오피스 구축: 안정적인 서비스 운영과 고객 지원을 위한 백오피스(어드민) 시스템을 설계하고 기능을 고도화해요.
• 대규모 트래픽 대응을 위한 인프라 관리: GCP, Docker, Kubernetes(GKE)를 활용하여 대규모 트래픽에도 확장 가능하고 안정적인 인프라를 구축하고 운영해요.
• 개발 생산성 향상을 위한 자동화: Github Actions를 이용해 CI/CD 파이프라인을 구축하고, 테스트 및 배포 자동화를 통해 개발 생산성을 높여요.
