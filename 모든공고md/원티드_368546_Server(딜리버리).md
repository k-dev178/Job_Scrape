## 회사 소개

라이더배달비서비스팀은 라이더 배달비의 계산·지급 정책과 시스템을 설계·운영합니다.
배달 품질을 높이기 위해 프라이싱 효율화를 모색하며,
다양한 서비스와 시스템으로 배달 경험을 지속적으로 개선하고 있습니다.
개발자는 PM, PA와 한 팀으로 협업하며,
고객에게 더 나은 가치를 전하기 위해 함께 고민하는 과정에서 성장합니다.
올해는 라이더 특성에 기반한 개인화된 배달료를 제공해 기존 도메인을 고도화하고,
배달처리비 전반을 제어하는 자동화 시스템 구축 로드맵을 수립하며 변화를 준비하고 있습니다.
배달 품질 개선에 주도적으로 기여하고, 새로운 도전을 함께 만들어갈 동료를 기다립니다.

## 주요 업무

• 배달비용 효율 향상을 위한 프로덕트 설계·개발
• AWS 기반 인프라에서 확장성과 안정성을 고려한 배달료 도메인 유지보수
• 타깃 프라이싱을 위한 세그먼트 고도화 설계·개발
• 모니터링 시스템 고도화

## 자격 요건

• 5년 이상의 Java Spring Boot 개발 실무 경력 또는 그에 준하는 역량을 갖춘 분
• AWS 환경에서의 서비스 개발·운영 (EC2, S3, RDS 등 활용) 경험이 있는 분
• RESTful API 기반 서비스 개발 경험이 있는 분
• 지속적인 모니터링과 A/B 테스트를 통한 데이터 기반 문제 발굴·해결 경험이 있는 분

## 우대 사항

• 대규모 분산 시스템 아키텍처 설계·개발 경험이 있는 분
• 마이크로서비스(MSA)·Event-driven 아키텍처 경험이 있는 분
• 협업 부서와의 원활한 커뮤니케이션 역량을 갖춘 분
• 주도적으로 과제를 발굴하고 추진하는 업무 방식을 가진 분
• 원활한 영어 커뮤니케이션 역량을 갖춘 분
