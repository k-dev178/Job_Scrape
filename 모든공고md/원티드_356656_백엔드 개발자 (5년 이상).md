## 주요 업무

• MSA 기반 도메인 서비스 개발 및 고도화: Spring Boot 환경에서 도메인 서비스를 개발합니다. MariaDB, Redis를 활용하며, Feign Client 및 REST API 기반 통신과 서킷 브레이커 등 안정성 확보를 위한 아키텍처를 설계하고 구현합니다.
• 이벤트 기반 아키텍처(EDA)로의 확장: 현재 메시징 용도로 사용 중인 Kafka를 향후 이벤트 기반 아키텍처로 확장하는 로드맵을 주도적으로 설계하고 팀과 함께 만들어갑니다.
• 시스템 성능 개선 및 배포 운영: k6를 활용한 성능 테스트 및 튜닝을 진행하며, Kubernetes 기반의 배포 및 모니터링 환경을 인프라/데브옵스 동료들과 협업하여 운영합니다.
• [중장기 과제] 검색 경험(UX) 고도화: 서비스 성장에 발맞춰 Elasticsearch 기반의 검색 엔진을 최적화하고 사용자 검색 경험을 개선합니다.
• 개발 문화 주도: 적극적인 코드 리뷰와 아키텍처 설계 논의를 통해 팀의 전반적인 기술 역량을 높이는 데 기여합니다.
