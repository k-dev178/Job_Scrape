## 회사 소개

우리는 스포츠와 e스포츠 팬 경험을 혁신하는 ‘RORR’를 운영하는 팀입니다.
팬의 응원이 경기의 흐름을 바꾸는 새로운 엔터테인먼트를 만들고 있으며, 기술과 창의성으로 글로벌 스포츠 문화를 재정의합니다.

## 주요 업무

• RORR Extension · Web · Admin 콘솔과 연동되는 API 및 서버 개발
• 실시간 LCK 경기 데이터를 활용한 실시간 이벤트 처리(Boost, 골드 그래프, 플레이어 스탯 등)
• 실시간 Webhook, WebSocket, Pub/Sub 기반 이벤트 인프라 구축
• 사용자 행동 데이터 수집 및 지표 관리(Data Pipeline)
• AI 기반 개인 코치/추천/대화 페르소나(Companion) 기능 개발
• LLM 기반 Prompt Engine, Recommender Engine, 대화 세션 관리 서버 개발
• 유저 프로필/행동 데이터 기반 Personalization Layer 구축
• AI 모델 추론 서버(LLM API, Vector DB 등)와 백엔드 연동
• 지속적인 성능 개선(A/B Test, Latency Optimization)
• 서버 안정성, 로그 모니터링, 장애 대응 구조 설계
• 서비스 확장을 고려한 모듈형 아키텍처 설계
• 배포 자동화(CI/CD) 및 운영 효율화
