## 회사 소개

AI 기반 패션/커머스 이미지 생성 플랫폼 Draph Art를 운영하는 스타트업입니다. 생성형 AI 기술로 브랜드와 셀러가 고품질 상품 이미지를 빠르고 저렴하게 제작할 수 있도록 돕고 있습니다.

• FastAPI 기반 API 서버 설계 및 개발
• Celery + Redis를 활용한 비동기 작업 큐 설계 및 운영
• PostgreSQL 데이터 모델 설계 및 쿼리 최적화
• AWS 인프라 구성 및 운영 (EC2, S3, RDS, CloudWatch)
• Docker 기반 Blue/Green 무중단 배포 파이프라인 유지보수
• Prometheus 기반 서버 모니터링 및 알람 운영
• 장애 감지 및 자동 복구 시스템 개발 및 유지보수
• 외부 API 연동 및 서드파티 서비스 통합 개발
