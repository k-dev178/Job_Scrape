## 회사 소개

[합류하게 될 팀에 대해 알려드려요]
• 토스플레이스는 결제 단말기와 POS를 비롯해 사장님의 매장 운영을 돕는 다양한 제품과 서비스를 만들고 있어요. 제품과 서비스가 성장하는 과정에서도 안정적인 결제 경험과 매장 운영을 제공할 수 있도록 신뢰성과 확장성을 중요한 가치로 생각해요.
• Server Platform Team은 제품들이 빠르고 안정적으로 개발·배포·운영될 수 있는 공통 기술 기반을 만들어요. Server Developer, DevOps Engineer, SRE, DBA가 각자의 전문성을 바탕으로 함께 문제를 해결해요.
• 서버 플랫폼 개발자는 여러 제품에 걸친 공통 관심사를 플랫폼 서비스와 라이브러리로 제공하고 운영해요. 통합 약관, 인증·인가, API Gateway부터 메시징과 연결 관리까지 제품 전반에 필요한 공통 기능을 책임져요.
• 플랫폼을 사용하는 개발자의 요구와 불편을 이해하고, 문제 발견부터 설계·구현·도입과 운영까지 함께해요. 공통 기능의 일관성과 신뢰성을 높이고, Internal Developer Platform과 개발 도구를 통해 개발 생산성과 서비스 품질을 개선해요.
• 각 제품팀은 자신이 만드는 서비스의 안정성을 책임지고, 서버 플랫폼 개발자는 제품팀이 활용하는 공통 서비스와 라이브러리의 품질과 운영을 책임져요. DevOps가 제공하는 인프라·배포 기반과 SRE가 발전시키는 신뢰성 기준을 함께 활용하며 문제를 해결해요.

## 주요 업무

[합류하면 함께할 업무예요]
• 통합 약관, 인증·인가, JWT 발급·JWKS 서비스와 API Gateway 등 여러 제품이 사용하는 공통 서비스를 개발하고 운영해요. 관련 조직과 제품팀의 요구사항을 바탕으로 공통 기능과 제품별 확장 범위, 데이터·API 계약을 설계해요.
• Feature Flag, A/B Test, 메시징 플랫폼 등 제품 개발과 운영에 필요한 플랫폼을 만들어요. SSE Server, MQTT Broker처럼 지속적인 연결을 다루는 서비스도 운영하며, 각 플랫폼의 특성에 맞춰 가용성, 확장성, 상태 관리와 장애 복구 방식을 개선해요.
• Metric, Logging, Distributed Lock, Messaging 등 서버 개발에 반복적으로 필요한 기능을 공통 라이브러리와 모듈로 제공해요. 플랫폼 서비스를 쉽게 활용할 수 있는 연동 라이브러리를 함께 만들고, 사용하기 쉬운 인터페이스와 확장 지점을 설계해요. 현재는 Java/Kotlin과 Spring 기반의 개발 환경을 중심으로 제공하고 있어요.
• 개발·운영 과정의 반복 작업과 불편을 발견하고, Internal Developer Platform과 개발 도구로 해결해요. 공통 기능의 이용, 서비스 구성과 운영 정보 확인 등 개발 흐름을 개선하고, DevOps와 함께 인프라·배포 기능을 연동해요.
• 공통 서비스와 라이브러리의 변경이 사용 팀에 미치는 영향을 관리해요. 테스트, 호환성과 버전 관리, 점진적 적용과 마이그레이션 방식을 설계하고, 문서·예제·도입 도구를 통해 제품팀의 적용을 지원해요.
• 담당 플랫폼의 진단에 필요한 관측 데이터를 제공하고, 장애 대응·복구·성능 개선과 재발 방지를 책임져요. DevOps, SRE, DBA와 함께 여러 계층에 걸친 문제를 해결하고, 주요 장애에서 얻은 학습을 담당 플랫폼의 코드와 운영 방식에 반영해요.
• 사용 팀의 요구와 피드백, 플랫폼의 운영 현황을 바탕으로 개선 과제의 목표와 우선순위를 정해요. 실제 적용 범위, 개발·운영 시간, 반복 작업량과 서비스 품질의 변화를 통해 개선 효과를 확인해요.

## 자격 요건

[이런 분과 함께하고 싶어요]
• 하나 이상의 프로그래밍 언어와 서버 개발 환경을 깊이 있게 활용해 프로덕션 소프트웨어를 설계·구현하고 운영한 경험이 있는 분을 찾아요. 테스트와 리뷰, 변경 관리를 통해 소프트웨어의 품질을 지속적으로 높일 수 있어야 해요.
• 반복되는 개발·운영 문제를 재사용 가능한 구조, 공통 라이브러리, 서비스 또는 개발 도구로 해결해 본 분과 함께하고 싶어요. 이를 실제 서비스에 적용하고 개선해 본 경험을 중요하게 생각해요.
• 서로 다른 요구사항에서 공통 기능을 찾아 적절한 경계와 인터페이스를 설계할 수 있는 분을 찾아요. 필요한 확장 지점과 공통화의 범위를 판단하고, 사용성·호환성·유지보수 비용을 함께 고려할 수 있어야 해요.
• 동시성, 상태 관리, 타임아웃, 재시도, 중복 처리와 부분 실패 등 분산 환경의 문제를 이해하고, 요구사항에 맞는 설계와 구현 방법을 선택할 수 있는 분을 찾아요.
• 운영 중인 시스템의 장애나 성능 문제를 가설과 데이터에 기반해 분석하고, 코드와 구조의 개선을 통해 해결해 본 분과 함께하고 싶어요.
• 새로운 기술 환경이나 익숙하지 않은 코드베이스의 구조와 동작을 이해하고, 기존 시스템의 제약을 고려해 필요한 변경을 구현하고 검증할 수 있는 분을 찾아요.
• 플랫폼을 사용하는 개발자의 문제를 구체화하고, 기술적 선택의 근거를 설명하며 여러 팀과 우선순위·도입·변경 과정을 조율할 수 있는 분과 함께하고 싶어요.
