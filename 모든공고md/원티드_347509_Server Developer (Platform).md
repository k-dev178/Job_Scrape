## 회사 소개

[합류하게 될 팀에 대해 알려드려요]
• 토스플레이스는 오프라인 결제 산업을 혁신하며 결제 생태계의 변화를 만들어가고 있어요.
• 서버 플랫폼 팀은 서버 플랫폼 개발자, DevOps 엔지니어, DBA로 구성되어 있어요. 서비스 장애가 생겨도 빠른 시간 내에 복구할 수 있도록 만반의 준비를 하고, 늘 안정적으로 운영될 수 있도록 지키는 것이 서버 플랫폼 팀의 역할이에요.
• 토스플레이스의 서버 개발자는 다양한 경력과 백그라운드를 가진 훌륭한 팀원들로 구성되어 있어요. ‘엔지니어링 데이’와 ‘문제 해결소’를 통해 기술 정보, 고민과 해결책 등을 공유하고, 조언도 주고받아요. 함께 더 나은 해답을 함께 찾아가며 성장할 수 있어요.

## 주요 업무

[합류하면 함께할 업무예요]
• 모든 서비스를 뒷받침하는 플랫폼을 개발/운영하고, 장애와 관련 있는 부분을 모니터링하고 개선해요. 서버 플랫폼과 관련된 모든 영역에 기여할 수 있어요.
• 토스플레이스의 Server Developer가 Java/Kotlin, Spring Framework를 이용하여 개발할 때 공통적으로 필요한 기능들(Metric, Logging, Distributed Lock, Messaging 등)을 모듈화하여 제공해요.
• 토스플레이스에서 사용되는 공통 관심사의 플랫폼 서비스(API Gateway, Monitoring & Alert System 등)를 개발하고 운영해요.
• 토스플레이스의 서버 인프라를 모니터링하고, 장애를 빠르게 감지하고, 빠르게 회복할 수 있도록 노력하고 있어요.
• 전체 시스템적인 관점에서 더 나은 아키텍처에 대해 고민하고 개선해요.
