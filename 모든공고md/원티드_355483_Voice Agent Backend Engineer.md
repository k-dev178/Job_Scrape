## 회사 소개

vox.ai는 음성으로 비즈니스가 일하는 방식을 다시 쓰는 회사입니다.
콜센터의 인바운드 응대, 아웃바운드 세일즈, 고객 만족 조사처럼 사람과 사람이 전화로 만나야 했던 모든 순간을 진짜 사람처럼 대화하는 음성 AI 에이전트로 풀어내고 있습니다. 국내 엔터프라이즈와 미들마켓 고객들이 vox.ai 위에서 월 수십만 통의 통화를 처리하고 있으며, 단순 자동응답이 아닌 "끝까지 일을 마무리하는 음성 에이전트"를 만드는 것이 우리의 목표입니다.
이 비전을 실현할 수 있는 vox.ai 팀만의 이유가 있습니다.
STT, LLM, TTS, 텔레포니, 실시간 오케스트레이션까지 음성 AI의 풀 스택을 직접 다루는 팀이며, 모델사들의 최신 기술 동향을 즉시 프로덕션에 반영할 수 있을 만큼 빠른 사이클로 제품을 출시해 왔습니다. 무엇보다, 매일 수 밀리초 단위의 지연을 줄이기 위한 의사결정이 일상인 환경에서 일합니다.
우리는 남들이 가지 않는 길을 가되, 맞아야 합니다.
그래서 빠르게 시도하고, 실패에서 배우고, 잘되는 것에 집중합니다. 함께 만들어갈 분을 기다립니다.

## 주요 업무

백엔드 팀은 vox.ai의 모든 음성 에이전트가 작동하는 기반 시스템을 만듭니다. 프롬프트와 플로우 오케스트레이션, 도구 호출, 통화 라이프사이클 관리, 텔레포니 연동까지 — 사용자가 대시보드에서 클릭 한 번으로 만든 에이전트가 실제 전화를 받기까지 거쳐 가는 모든 레이어를 책임집니다.
우리는 매주 새로운 기능을 출시합니다. 고객은 매일 새로운 유스케이스를 들고 오고, 모델 생태계는 분기마다 판이 뒤집힙니다. 이 환경에서 견고한 추상화를 유지하면서도 빠르게 출시할 수 있는 백엔드를 함께 만들어갈 분을 찾고 있습니다.
• vox.ai 플랫폼의 코어 백엔드를 설계·구현·운영합니다.
• 에이전트 빌더, 플로우 오케스트레이션, 도구 호출, 통화 라이프사이클 관리 등 핵심 도메인의 API를 설계합니다.
• 텔레포니, 데이터, AI 레이어를 잇는 통합 레이어를 구축하고 안정적으로 운영합니다.
• 실시간 통화 데이터와 이벤트 파이프라인을 설계하고 정확성을 보장합니다.
• 음성 에이전트의 품질을 검증하는 테스트·평가 프레임워크와 관측성 대시보드를 직접 구축합니다.
• 고객 온보딩과 프로덕션 이슈 디버깅을 직접 지원하며, 현장에서 발견한 문제를 제품 개선으로 연결합니다.
• 코드 리뷰와 리팩토링을 통해 협업하기 좋은 코드베이스를 유지합니다.
• 고객의 새로운 요구사항을 빠르게 프로토타이핑하고, 반복 가능한 패턴으로 정착시킵니다.
