## 회사 소개

전사 데이터의 구조와 기준을 설계하고, 데이터 기반 의사결정의 토대를 만들어가는 일. 함께하실 분을 찾습니다.
데이터 아키텍처 원칙과 표준을 정의하고, 핵심 IT 변화에 따른 데이터 구조·품질·성능 리스크를 관리하며 데이터 아키텍처 로드맵을 수립·운영해 나가는 역할이에요.

## 주요 업무

• 전사 데이터 아키텍처 전략 및 표준, 로드맵 수립·운영
• 데이터 표준, 품질, 데이터 구조에 대한 검토 및 개선
• 시스템 간 데이터 흐름, 연계·통합 구조 및 데이터 플랫폼 아키텍처 설계
• 데이터 모델링, SQL 성능, 데이터 이관·정합성 검증 및 데이터 리스크 관리

## 자격 요건

• 4년제 컴퓨터 공학 또는 직무 관련 전공자
• 데이터 관련 업무 수행 경력 8년 이상 (DA 업무 경력 5년 이상)
• 이해관계자 간 적극적인 협업 및 커뮤니케이션 역량을 보유하신 분
• 복잡한 비즈니스 프로세스를 데이터 구조로 해석하고 체계화할 수 있는 역량을 보유하신 분
• 데이터 모델링, SQL 성능 튜닝, 데이터 흐름 설계에 대한 깊은 이해를 보유하신 분

- 금융업 유경험자, 전자금융감독규정에 대한 이해 보유자
- 금융권 차세대, 데이터 통합, 데이터 전환 또는 데이터 플랫폼 구축 프로젝트 수행 경험자
- DW, 데이터 마트, 데이터 레이크하우스, ETL/ELT, 데이터 파이프라인 구조에 대한 이해를 보유하신 분
