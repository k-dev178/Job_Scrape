- 경력: 3~5년
- 원문: https://www.wanted.co.kr/wd/370627

- 기술: TypeScript, Node.js, Bun, MySQL, AWS, GCP
- 지역: 경기 안양시 동안구 시민대로327번길 24, 5층

## 회사 소개

투바이트는 앱 내에서 바로 실행되는 H5 게임 플랫폼을 구축부터 게임 소싱, 로컬라이징, 운영까지 H5 게임 서비스를 위한 전 과정을 통합 제공하는 스타트업입니다.
투바이트와 함께 성장할 열정과 역량을 갖춘 백엔드 개발자를 모집합니다.

## 주요 업무

• TypeScript / Bun / Elysia 기반 API 서버 설계·개발·운영
• DrizzleORM + MySQL 기반의 데이터 모델링과 쿼리 최적화
• B2C 트래픽을 견디는 안정적이고 확장 가능한 서버 아키텍처 설계
• 신규 기능 개발 및 기존 서비스 고도화
• 직접 만든 서비스를 GCP 위에 배포하고 안정적으로 운영 (CI/CD·모니터링·장애 대응 포함)
• 서버 성능·비용을 함께 살피며 더 나은 운영 환경을 만드는 일

## 자격 요건

• 백엔드 개발 경력 3~5년차 수준
• TypeScript / Node.js 생태계에 능숙하고, 서버 사이드 개발에 대한 탄탄한 이해
• RDB(MySQL 등) 설계와 쿼리 최적화 경험
• 클라우드(GCP, AWS 등) 환경에서 서비스를 배포·운영해 본 경험
• 직접 만든 기능을 운영까지 챙기는 데 거부감이 없고, 넓게 배우는 것을 즐기는 분

## 우대 사항

• Bun / Elysia / DrizzleORM 사용 경험 (혹은 경험이 없더라도 빠르게 익힐 의지가 있는 분)
• GCP 환경 운영 경험 (GKE, Cloud Run, Cloud SQL 등)
• IaC(Terraform 등), 컨테이너(Docker/Kubernetes) 운영 경험
• B2C 대용량 트래픽 서비스 운영 경험
• 작은 팀에서 폭넓은 역할을 맡아본 경험
