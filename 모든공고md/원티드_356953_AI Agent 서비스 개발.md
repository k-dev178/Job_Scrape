## 회사 소개

알엑스(RX)는 세계 최고 수준의 SMR 설계 기술력을 보유하고 이를 지속적으로 확장해 나가는 딥테크 스타트업입니다.
최고의 엔지니어들이 축적된 경험을 기반으로 글로벌 수준의 SMR 엔지니어링 역량을 고도화하고 있으며, 세계 최고 수준의 안전성과 고객이 실제 도입 가능한 경제성을 동시에 구현하는 것을 목표로 합니다.
AI 솔루션팀에서는 에너지·원자력 도메인에 특화된 AI Agent 서비스를 구축하고 있으며, LLM 기반 시스템을 설계·구현할 백엔드/풀스택 개발자를 찾습니다.

## 주요 업무

• LLM 기반 AI Agent 아키텍처 설계 및 구현 (LangChain, LangGraph, CrewAI 등 활용)
• RAG 파이프라인 구축: 벡터DB 설계, 임베딩 최적화, 검색 성능 튜닝
• 에너지/원자력 도메인 특화 Agent 워크플로우 개발 (설계 검증, ASME 코드 체크, 기술문서 생성 등)
• API 서버 설계·개발 및 클라우드 인프라 운영 (AWS/GCP)
