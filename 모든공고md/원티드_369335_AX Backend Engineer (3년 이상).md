## 주요 업무

AX Engineering Team은 LLM·RAG·Knowledge Graph 기반 AI 솔루션을 실제 고객 운영 환경까지 책임지는 기술 실행 조직입니다.
AI Lab의 모델, AI 데이터팀의 데이터 자산을 결합하여 공공·민간 고객사가 사용하는 AI 시스템으로 완성·배포합니다.
본 포지션은 LLM 서빙·RAG·Knowledge Graph를 떠받치는 백엔드 아키텍처와 공통 프레임워크를 설계하고, 다양한 고객 환경(On-premise / Cloud)에 맞춘 딜리버리 엔지니어링을 책임집니다.
[대표 프로젝트]
• TechGPT : 특허·논문·기업·뉴스 통합 검색 시스템 (컨소시엄 과제)
• 공공 AX : 공공기관 대상 AI 솔루션 구축 (망분리·보안 요구 환경)
• 자동화보고서 : LangGraph 멀티턴 Agent 기반 분석 리포트 시스템
[중요] 본 포지션은 포트폴리오를 필수로 제출해주셔야하며, 포트폴리오가 첨부되지 않을 경우 불합격처리 됩니다.
