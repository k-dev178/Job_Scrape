[ 합류하게 될 Server Platform Team을 소개해요 ]
Server Platform Team은 라포랩스의 서버 개발자들이 더 높은 생산성을 낼 수 있는 플랫폼을 만드는 팀이에요. 좋은 플랫폼 하나가 모든 개발자의 일하는 방식을 바꿀 수 있기 때문에, 더하기(+)를 넘어 곱하기(×) 로 임팩트를 만들어 낼 수 있는 역할을 하고 있어요.
서비스와 조직이 성장하면서, 플랫폼이 만들어낼 수 있는 임팩트도 훨씬 커졌어요. 풀어야 할 문제도, 시도해볼 수 있는 것도 많아진 지금, 함께 이 임팩트를 만들어갈 분을 찾고 있어요.
[ Server Platform Team은 이런 문제를 풀고 있어요 ]
서버플랫폼팀의 업무는 크게 두 가지 축으로 이루어져 있어요.
1. 플랫폼 — 모든 서버 개발자의 생선성을 높이는 기반
우리 팀의 주 고객은 스쿼드의 서버 개발자들이에요. 이들의 성공을 돕는 것을 임팩트로 측정하고 있어요. 개발 테스트 배포 모니터링에 이르는 스쿼드의 제품 개발/출시 사이클 전반에서 더 높은 생산성을 낼 수 있도록, 회사와 조직의 방향, 개발 문화를 고려한 적절한 플랫폼을 설계해요.
창업 초기의 모놀리스에서 마이크로서비스로, 수동 배포에서 자동화된 파이프라인으로 — 서비스가 성장하는 매 단계마다 시대가 요구하는 플랫폼을 만들어 왔어요.
그리고 현재, 라포랩스는 모든 구성원이 AI 코딩 에이전트와 함께 개발하는 시대에 서 있어요. 지금 Server Platform Team의 미션은 AI Agent가 회사의 코드, 도메인, 히스토리를 깊이 이해하고, 개발자들의 제품 개발 사이클을 더 빠르고 안정적으로 만들 수 있는 플랫폼으로 진화시키는 것이에요.
＜그동안 이런 일을 했어요＞
• 마이크로서비스 공통 라이브러리 제공
◦ 서비스마다 반복되는 인프라 코드(트랜잭션 메시징, 캐싱, 인증, 분산락 등)를 공통 라이브러리로 만들어, 스쿼드 개발자가 비즈니스 로직에만 집중할 수 있도록 했어요.
• 피쳐별 End-to-End 테스트 환경 제공
◦ 스쿼드에서 개발 중인 피쳐를 데이터가 격리된 개발 환경에 배포하고 End-to-End 로 테스트할 수 있는 환경을 설계하고, 이를 쉽게 활용할 수 있는 CLI 도구를 개발했어요.
• Spring Boot 2 3 전환
◦ 전체 마이크로서비스의 Spring Boot 메이저 버전 업그레이드를 계획하고, 호환성 이슈를 해결하며 단계적으로 마이그레이션을 완수했어요.
• API Gateway 도입 및 운영
◦ 인증, 보안, 라우팅 등 공통 관심사를 Gateway 에서 처리하여 각 서비스의 부담을 줄이고, API 개발 표준을 만들어가고 있어요.
2. SRE — 서비스 안정성의 파수꾼
수백만 고객이 사용하는 퀸잇 서비스의 신뢰성과 성능을 전반적으로 책임져요.
서비스가 커지면서 안정성의 기준도 함께 높아져 왔어요. 이런 노하우를 체계화하고 전파하여 각 서비스 오너가 스스로 더 높은 안정성을 확보할 수 있도록 돕고 있고, 최근에는 AI Agent 가 장애 감지와 진단을 보조하는 방향도 함께 고민하고 있어요.
• 분산 환경 모니터링 체계 구축
◦ 마이크로서비스 전환 후 로그 추적이 어려워진 문제를 해결하기 위해, 분산 트레이싱과 접근 로그 수집 파이프라인을 설계했어요.
• 마케팅 대비 자동 서버 증설 시스템
◦ 유동적인 마케팅 이벤트 스케줄로 인해 트래픽 급증에 수동으로 대응하던 비효율을 해결하기 위해, 트래픽 패턴을 고려한 자동 증설 시스템을 만들었어요.
• 서버 안정성 개선 및 리소스 최적화
◦ 비정상적인 Latency 와 CPU/Memory 사용을 탐지하고 AsyncProfiler, Heapdump 를 이용하여 분석하고 지속적으로 시스템을 개선하고 있어요.
• 서버 Bootup 시간 및 초기 지연 개선
◦ Spring Application 의 초기 구동 시간을 줄이기 위해 Boot up 과정을 분석하고 최적화했어요.
◦ Cold start 시 발생하는 초기 요청 지연의 원인을 분석하고, 다양한 조치를 통해 런타임 전반의 성능을 향상시켰어요.

## 주요 업무

[ 합류하시면 이런 환경에서 일해요 ]
1. AI 시대 플랫폼 엔지니어링의 최전선
라포랩스에서는 모든 개발자가 AI 에이전트와 함께 개발하고, 모든 팀이 Claude Code를 활용해 사업팀도 필요한 애플리케이션을 직접 만들고 있어요. (관련 아티클)
이렇게 빠르게 변화하는 환경 속에서 생산성과 안정성 사이의 적절한 가드레일을 설계하는 경험을 할 수 있어요.
실제로 AI-Driven Development Life Cycle 전환을 돕기 위해 서버 개발 워크플로를 체계적인 Agent Skill로 만들어 사내 마켓플레이스를 통해 배포하고 있으며, AI Agent 에게 SRE 노하우를 전파하여 서비스 안정성을 높이는 방법을 함께 고민하고 있어요.
2. 높은 오너십으로 일하는 환경
단순히 정해진 기술부채만 해결하는 것이 아니라, 함께 라포랩스 서버 개발자들을 위한 플랫폼의 로드맵을 직접 고민하고 실행할 수 있는 환경이에요. 조직 내 발생하는 여러 병목들을 찾아 문제를 파악하고, 해결 방법을 제안하고, 직접 실행해 보는 경험을 할 수 있어요.
3. 실패를 함께 배우는 문화
장애가 발생하면 개인을 탓하지 않고, 시스템의 취약점을 함께 찾아 개선해요. "누가 잘못했는가"가 아니라 "어떻게 하면 다시 발생하지 않을까"를 함께 고민하는 팀이에요.

## 자격 요건

[ 서버플랫폼팀은 이런 분과 함께하고 싶어요! ]
• 주도적으로 문제를 발견하고 정의하는 분
◦ 팀과 조직의 병목이 되는 구간을 발견하고, 문제를 스스로 정의해내는 것이 중요해요.
◦ 기술이 좋아서 도입하는 것이 아니라, 이 문제를 풀기 위해 기술을 선택하는 분이면 잘 맞을 수 있어요
• 구성원과 공감대를 만들어가는 분
◦ 좋은 플랫폼을 만드는 일은 때로 개발 문화를 함께 바꿔나가는 일이기도 해요. 기술적으로 올바른 방향을 구성원들에게 설명하고 공감대를 형성하며, 변화를 자연스럽게 이끌어가는 과정이 중요해요.
◦ 발견한 문제를 팀원들과 함께 고민하고 리뷰하면서, 그 변화를 주도적으로 이끄는 분이면 잘 맞을 수 있어요.
• 끈기있게 완수해내는 분
◦ 플랫폼을 바꾸는 일은 달리는 자동차의 바퀴를 교체하는 것과 같아요. 제품 개발에 병목을 최소화 하면서 플랫폼을 개선해야 하기 때문에, 장기적으로 진행되는 마이그레이션도 끝까지 완수해내는 끈기가 필요해요.
◦ 장애나 성능 이슈를 만났을 때, 표면적인 증상 너머의 원인을 찾아가는 과정에 흥미를 느끼는 분이면 좋아요. 로그를 뒤지고, 가설을 세우고, 하나씩 소거해가며 진짜 원인에 도달하는 과정 자체를 재미있어하는 분이라면 잘 맞을 거예요.
