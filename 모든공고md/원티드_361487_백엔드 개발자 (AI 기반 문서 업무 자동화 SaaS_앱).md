# 백엔드 개발자 (AI 기반 문서 업무 자동화 SaaS/앱)

- 출처: 원티드
- 회사: 청량산김치
- 경력: 4년 이상
- 원문: https://www.wanted.co.kr/wd/361487
- 공고번호: 361487
- 기술: TypeScript, Node.js, MySQL, PostgreSQL, REST API
- 지역: 서울 광진구 능동로 120

## 회사 소개

핵심 내용
-외부 STT/OCR/AI API를 활용해 파일럿 가능한 MVP 기능을 구현하는 단계입니다.
-핵심 기능 흐름 “앱에서 녹음 파일·계약서 이미지 업로드 서버 저장 SaaS에서 외부 API 연동 SaaS에서 디지털 문서 초안 생성 조회·수정·저장”

## 주요 업무

주요 역할
- 앱에서 업로드한 녹음 파일 및 계약서 이미지를 서버로 전송·저장하는 API 개발
- STT/OCR/AI API 등 외부 API를 연동해 녹음·이미지 데이터를 디지털 문서 초안으로 변환하는 기능 개발
- 외부 API 연동 시 개인정보 노출을 최소화하는 데이터 처리 방식 설계 및 구현
- SaaS에서 변환된 문서를 조회, 수정, 저장할 수 있는 API 개발
- 사용자, 기관, 수급자, 계약서, 문서 데이터 등 MVP에 필요한 기본 데이터 구조 개발
- 로그인, 사용자 역할 구분, 기본 권한 관리 기능 개발
- 파일 업로드 및 파일럿 운영에 필요한 기본 저장소, 배포 환경, 로그 확인 구조 구성

- 로그인, 인증, 권한 관리에 대한 기본 이해
- 클라우드 환경에서 서비스를 배포해본 경험
