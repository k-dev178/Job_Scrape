## 주요 업무

1. AWS AgentCore & MCP 기반 에이전트 인프라 및 거버넌스 구축
• 에이전트 인프라 아키텍처링: AWS AgentCore를 프로덕션 환경에 주도적으로 도입하여 에이전트의 권한 제어
(Identity/Policy)를 체계화하고 보안 거버넌스를 확립합니다.
• 도구(Tool) 및 데이터 표준화: MCP(Model Context Protocol) 표준 프로토콜을 구현하여 WMS/OMS/LMS 등
사내 핵심 데이터 소스를 에이전트 시스템에 안전하게 연동합니다.
2. AI 관측성(Observability) 및 신뢰성 관리
• 실시간 AI 모니터링 체계 수립: AWS CloudWatch를 연동하여 에이전트의 실행 지연 시간(Latency), 토큰 호출 비용,
도구 호출 정확도(Tool Selection Accuracy)를 실시간 감시하는 대시보드 및 알림 시스템을 구축합니다.
• 지속 가능한 품질 개선(CI/CD for LLM): 피드백 로그 분석 및 자가 진단 기능을 자동화하여 에이전트의 환각
(Hallucination) 현상을 방어하고 답변 정확도를 지속적으로 모니터링합니다.
3. LangGraph 기반 멀티 에이전트 오케스트레이션 및 파이프라인 최적화
• 멀티 에이전트 확장: Gemini 및 LangGraph를 활용하여 복잡한 물류/풀필먼트 비즈니스 로직을 수행하는 도메인
특화 멀티 AI Agent 시스템을 구축합니다.
• 데이터 파이프라인 및 FinOps: FastAPI와 BigQuery를 활용해 정형/비정형 데이터를 구조화하는 대규모 LLM 데이터
파이프라인을 운영하며, AWS 인프라 비용 대비 품질(Cost-to-Quality) 최적화 전략을 제시합니다.
