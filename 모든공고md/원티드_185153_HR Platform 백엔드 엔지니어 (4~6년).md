## 회사 소개

AINJOB은 AI 기반 HR/채용 플랫폼을 신규 개발하고 있습니다. 백엔드 개발자는 이미 정의된 핵심 엔티티를 바탕으로 주요 기능을 구현하고, 데이터·API·AWS 연계를 안정적으로 개발합니다. 시니어 개발자로 성장하는 데 필요한 핵심 역량을 확보할 수 있습니다.

## 주요 업무

1. 백엔드 기능 구현
• Spring Boot 기반 HR Platform 기능 개발
• 지원자/기업/공고/ATS/메시지/알림 등 기능 개발
• REST API 개발 및 간단한 구조 개선
2. RDB/SQL 기반 기능 개발
• 정의된 스키마를 기반으로 한 데이터 정합성을 고려한 RDB 설계, 구현
• 검색·필터·정렬 쿼리 작성
• 정의된 상태 전이에 따른 데이터 변경 로직 구현
• 성능 (인덱스/쿼리) 최적화 작업
3. AWS 기반 서비스 구축 및 운영
• ECS / RDS / S3 기반 서비스 구축 및 기능 개발
• SQS 기반 비동기 Job 처리 개발
• 로깅/모니터링 기본 작업
4. 품질 향상 및 안정성 개선
• 간단한 버그 해결 및 이슈 대응
• 코드 리뷰 참여
• 테스트 시나리오 작성 및 운영 자동화
5. 팀 협업 및 문서화
• API 문서(OpenAPI/Swagger) 작성 및 유지
• 개발 산출물(README 등) 간단 문서화
• 기획/프론트/디자이너와 협업
6. 역할 및 담당 업무는 서비스 개발 목표와 팀 구성에 따라 협의하에 조정될 수 있습니다
