## 주요 업무

합류하면 이런 일을 해요
• 금융기관의 데이터와 업무 흐름을 이해하고, AI 기반 의사 결정 시스템의 구조를 설계해요.
• 고객사의 기존 시스템과 연동하여, 실제 운영 환경에서 사용할 수 있도록 구축하고 개선해요.
• 운영 과정에서 발생하는 이슈를 점검하고 해결하며, 시스템이 안정적으로 동작하도록 관리해요.
• 프로젝트 경험을 바탕으로, 확장 가능한 구조와 표준을 만들어, 더 많은 고객사에 적용할 수 있는 기반을 만들어요.

## 우대 사항

이런 경험을 가진 분이면 더 좋아요
• B2B SaaS / 엔터프라이즈 솔루션 구축 경험이 있는 분
• 금융 / 핀테크 도메인 경험(여신, 심사, 리스크 등)을 보유한 분
• AWS / GCP / Azure 등 Cloud 아키텍처 경험이 있는 분
• Kubernetes, Docker 등 컨테이너 기반 환경 경험이 있는 분
• 데이터 파이프라인 또는 ML 시스템에 대한 이해가 높은 분
• Solution Architect / Technical Consultant / Pre-sales 경험이 있는 분
이런 면에서 특별한 포지션이예요
• 단순 솔루션 도입이 아니라, AI 기반 금융 의사 결정에 실제로 쓰이는 시스템을 직접 설계하고 구현할 수 있어요.
• 기본 시스템을 개선하는 수준을 넘어, AI 기반 여신 프로세스를 새롭게 정의하는 경험을 할 수 있어요.
• 모델이나 기술에 그치지 않고 실제 금융 데이터와 연결해 비즈니스 성과를 만들 수 있어요.
• AI Agent 기반 자동화 시스템을 가장 먼저 다뤄볼 수 있어요.
• 글로벌 확장을 준비하는 과정에서, 여러 환경에 적용 가능한 “표준”을 만드는 초기 멤버로 기여할 수 있어요.
