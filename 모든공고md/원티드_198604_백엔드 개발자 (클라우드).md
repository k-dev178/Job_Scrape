# 백엔드 개발자 (클라우드)

- 출처: 원티드
- 회사: 그루매틱
- 경력: 3~7년
- 원문: https://www.wanted.co.kr/wd/198604
- 공고번호: 198604
- 기술: Python, AWS, Azure
- 지역: 성남시 분당구 정자로 2, 스파크플러스 분당점 103호

## 회사 소개

그루매틱에서 소프트웨어 개발팀에서 일할 유능한 백엔드 개발자를 찾고 있습니다. 그루매틱 웹 애플리케이션의 '서버측' 개발을 담당하게 됩니다. Python으로 코드를 작성하고 확장 가능한 클러스터를 클라우드에서 개발하는데 관심이 있다면 지원하세요.

## 주요 업무

- Python3을 사용하여 웹 애플리케이션과 상호 작용하는 서버 및 클러스터 개발
- 서버/웹 애플리케이션 유지 및 개선
- 최대 속도를 위해 애플리케이션 최적화 (도커 및 쿠버네티스 경험 환영)
- 혁신적인 웹 응용 프로그램을 개발하기 위해 프론트엔드 개발자, 웹 디자이너, 제품 관리자와 협업
- 사용자와 고객으로부터 피드백을 받고 클라우드 상에서 솔루션을 구축

## 자격 요건

- 백엔드 개발자로서 입증된 업무 경험 또는 교육
- 뛰어난 커뮤니케이션 스킬
- 원활한 팀워크 및 성과 기반 업무
- Python 3 및 Python 기반 웹 애플리케이션 프레임워크에 대한 실무 경험.
- 전체 웹 애플리케이션 개발 프로세스(설계, 개발 및 배포)에 대한 심층적인 이해
- AWS, Azure 또는 GCP와 같은 퍼블릭 클라우드에서 소프트웨어 개발 경험
- 급변하는 환경에서 잘 수행할 수 있는 능력
- 컴퓨터 학과 또는 관련 분야의 학사 학위
