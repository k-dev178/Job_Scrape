## 주요 업무

• 자사 신사업 및 기존 플랫폼 서비스의 백엔드 시스템 신규 개발 및 고도화
• Kotlin + SpringBoot 기반의 API 서버를 설계 및 구현
• AI 개발 도구(Claude Code 등) 적극 활용을 통해 개발 생산성 향상

## 자격 요건

• 대졸 이상 / 백엔드 개발 경력 4년 ~ 7년이신 분
• 객체지향 기반의 설계/구현에 능숙하며, 테스트 가능한 구조로 개발하시는 분
• Kotlin, Java, SpringBoot 기반의 RESTful API 개발 경험이 있으신 분
• JPA, Hibernate 등 ORM 사용 및 도메인 모델링 설계 경험이 있으신 분
• 기획을 빠르게 이해하고 구현 방향을 제시할 수 있는 분
• AI 개발 도구를 활용한 개발 경험이 있으신 분
• 해외 여행에 결격 사유가 없으신 분
